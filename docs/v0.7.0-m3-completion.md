# RunbookOS v0.7.0 M3 Completion

Status: **M3_READY_FOR_REVIEW** (offline implementation and verification)

## Implemented

- Added versioned M3 dataset/evaluation schemas and a separate 24-case held-out
  synthetic benchmark spanning web, application, database, network, and
  insufficient-evidence conditions.
- Cases include normal states, service/transport/network failures, conflicting
  observations, ambiguous signals, absent evidence, and observation-only cases
  that do not establish causality. Two hand-authored false causal claims are
  included as semantic-validator examples.
- Gold labels and annotation rationales live separately from model-facing
  incident context/evidence. The projection function returns only model input.
- Added a deterministic evaluator for diagnostic selection, classification,
  abstention, independently adjudicated semantic support, and confidence
  calibration. Undefined ratios remain JSON `null`.
- Added a file-only runner that validates the taxonomy/dataset and optionally
  consumes a prediction submission. It does not call a provider or executor.
- Added annotation guidance and an ADR mapping M3 to the actual M1/M2 schema.
- Generated JSON and Markdown fixture-validation reports. No model prediction
  performance is reported because no prediction submission was supplied.

## Limitations

Semantic labels must come from independent human review. Syntactic citation
validity is not semantic support. A small synthetic benchmark does not represent
production incident prevalence and cannot establish production calibration.
